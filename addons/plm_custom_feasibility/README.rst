PLM Custom - Feasibility Assessment
====================================

跨部門可行性評估模組。在接到潛在訂單或客戶詢問時，由業務/工程/產線/品保/採購/法規
六個部門各自評分 0-10，模組自動彙總為「可行 / 可行但有風險 / 不可行」三類決策結論。

模型
----

* ``plm_custom.feasibility`` — 評估主檔（含 5 個面向分數與自動彙總）
* ``plm_custom.feasibility.score`` — 評分明細（每部門一筆）
* ``plm_custom.feasibility.wizard`` — 從銷售訂單/明細一鍵開立評估的 wizard

決策規則
--------

* 總分 = 五項分數加總 × 2（滿分 100）
* >= 80 → 可行 (feasible)
* 60-79 → 可行但有風險 (feasible_with_risk)
* < 60  → 不可行 (infeasible)

評分明細的「部門」與主檔五個面向的對應：

* 產線 → 產能分數
* 工程 → 技術分數
* 採購 → 料況分數
* 品保 → 法規分數
* 業務 → 風險分數
* 法規 → 選填，僅供記錄，不計入總分

核准與駁回（走通用簽核引擎）
------------------------------

核准與駁回一律走通用簽核引擎（``mfg_custom.approval.mixin``），表單上已不再
提供直接核准／駁回的按鈕，改為下列按鈕：

* 「送出評估」：草稿（``draft``）→ 評估中（``in_review``），需至少 1 筆評分明細
* 「送出簽核」：僅 ``in_review`` 狀態可送出，會依簽核規則建立簽核申請
* 「核准目前關卡」／「駁回」：委派給簽核引擎處理目前關卡
* 「取消簽核」：取消整份簽核申請，評估單退回草稿

狀態回寫：

* 所有關卡皆核准 → ``approved`` （通過）；核准前會檢查業務/工程/產線/品保/採購
  五個必要部門是否都已評分，未評分時會直接報錯
* 任一關卡駁回 → ``rejected`` （不通過）
* 取消簽核 → 退回 ``draft`` （草稿）
* 「取消」→ ``cancelled`` （取消）

示範簽核規則為「工程部核准 → 管理部核准」兩關，管理者可在
**MFG Custom > 設定 > 簽核規則** 自行調整。

來源
----

可從銷售訂單、銷售明細或手動建立；亦可透過 wizard 從 SO / SO line 直接帶入客戶與產品。

依賴
----

* mfg_custom_base
* mfg_custom_approval — 核准／駁回所用的通用簽核引擎
* sale
* mrp
* purchase
