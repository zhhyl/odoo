MFG Custom - Production Stage & Yield Rate
==========================================

為 ``mrp.production`` 加入生產階段區分與得料率自動計算。

功能
----

* **生產階段** ``mfg_custom_production_stage``：樣品 / 小批量 / 量產
* **階段變更日誌** ``mrp.production.stage.log``：記錄每次階段切換（含變更原因）
* **變更生產階段** 按鈕：開啟確認視窗（可填變更原因）後套用新階段
* **得料率** ``mfg_custom_yield_rate``：實際產出 ÷（依實際投入原料與 BOM 配比換算的
  理論產出）× 100，上限 100%；僅在 MO 狀態為 done 時計算，其餘情境顯示 0
* **期望得料率** ``mfg_custom_expected_yield_rate``：MO 上的期望值（預設 98%）；
  實際得料率低於此值時於表單／清單以紅色標示
* **BOM 預設階段** ``mfg_custom_default_production_stage``：在 BOM 上預設新建 MO 使用的階段
* **問題点 / 品檢計數**：安裝對應模組後自動統計並啟用 smart button
* **每日 cron** 重算得料率（每日 23:00）
* **得料率報表**：可列印含實際得料率與期望得料率比較的 PDF 報表

得料率的計算方式
----------------

得料率不是「產量 ÷ 標準用量」，而是「實際產出 ÷ 依實際投入換算的理論產出」：

* 實際產出：``move_finished_ids`` 中狀態為 done、且產品為該 MO 產品的數量加總。
* 理論產出：以「實際投入的原料總量 ÷ 每件成品的 BOM 配比總量」換算。例如 BOM 每件
  成品需 3 件原料、實際投入 30 件，理論產出即為 10 件。
* 得料率 = min(100, 實際產出 ÷ 理論產出 × 100)。

只有在 MO 狀態為 done 時才計算，其餘情境顯示 0。沒有 BOM 或沒有原料消耗時，
退而以「實際產出 ÷ 計劃數量」計算。少耗原料時理論產出降低（得料率上升）、
多耗原料時理論產出提高（得料率下降）。

依賴
----

* ``mfg_custom_base``：共用群組、序號、mail mixin
* ``mrp``：核心製造模組
* ``stock``：庫存模組（得料率需用 stock.move）

關聯模組
--------

* ``mfg_custom_issue`` （選擇性）：問題点計數與 smart button
* ``mfg_custom_quality`` （選擇性）：品檢計數與 smart button
* ``plm_custom_feasibility`` （選擇性）：樣品單關聯欄位

三者皆以「延遲參考」方式保留欄位／介面：安裝後自動生效，未安裝時欄位顯示為空
或計數為 0，不會造成錯誤。

安裝
----

直接安裝此模組即可，後續問題点／品檢／樣品評估模組建好後不需要重灌。
