MFG Custom - Purchase Approval
===============================

把 ``purchase.order``（RFQ）掛上本專案的通用簽核引擎
``mfg_custom.approval.mixin``，讓採購單可以直接送出多層簽核。

功能
----

* **表單按鈕**：採購單表單上多出「送出簽核 / 核准目前關卡 / 駁回 / 取消簽核」
  與「簽核狀態」statusbar。
* **送審前檢查**：送出簽核前會檢查單據狀態、是否有料、是否已指定供應商。
* **確認訂單閘門**：有匹配簽核規則但尚未核准時，按「確認訂單」會被擋下。
* **審批紀錄分頁**：採購單上可直接查看各關卡的核准人、決策、決策時間與審批意見，
  並可一鍵開啟對應的簽核單。
* **付款閘門**：廠商帳單登記付款時，會檢查關聯採購單是否已通過審批。
* **清單與篩選**：採購單清單顯示簽核狀態 badge；篩選器可依「待簽核」篩選。

簽核引擎既有能力一併適用
------------------------

* 多層關卡（``mfg_custom.approval.step``），核准人可為指定人員 / 指定群組 / 單據欄位
* 關卡金額門檻（最小 / 最大金額），預設對應 ``purchase.order`` 的 ``amount_total``
* 簽核期限（``due_days``）與每日 cron 逾期提醒
* Chatter 訊息與 email 通知
* 駁回後重新送出簽核可重啟流程

設定
----

安裝後到 **MFG Custom > 設定 > 簽核規則** 新增一條規則：

* **適用單據類型**：選「採購訂單」
* **適用條件 (domain)**：留空代表所有採購單都要簽核；可寫條件限定範圍，例如
  ``[("amount_total", ">=", 500000)]``
  （可用欄位：``amount_total``、``company_id``、``state``、``partner_id``、
  ``date_order``、``user_id``、``currency_id``）
* **簽核關卡**：新增關卡並挑選核准人。可用本模組提供的「採購簽核者」群組，
  或直接沿用 Odoo 原生的「採購：Administrator」/「採購：User」。

與 Odoo 內建「to approve」的關係
--------------------------------

Odoo 內建的採購單雙人覆核（``res.company.po_double_validation``，狀態 ``to approve``）
**完全保留不動**。兩者定位不同：

* Odoo 內建：金額覆核，1~2 關，核准者限採購經理
* 本模組：多部門業務簽核，關卡數與核准人由簽核規則定義

因此流程順序是「先完成本模組的簽核 → 再按確認訂單」。若公司同時啟用了內建的
「Levels of Approvals = Get 2 levels of approvals」，按確認訂單後仍會進入
``to approve`` 狀態，需採購經理再核一次；只要一套的話，把該設定改成
「Confirm purchase orders in one step」即可。

本模組**不會**改動採購單的原生狀態（``draft`` / ``sent`` / ``to approve`` /
``purchase`` / ``cancel``），簽核進度一律看「簽核狀態」欄位。

付款前的審批閘門
----------------

廠商帳單（``account.move``，``move_type='in_invoice'``）登記付款時，會檢查它關聯的
採購單是否已通過審批。

* **只管制「有匹配簽核規則」的採購單**。沒有簽核規則的採購單
  （``approval_rule_id`` 為空）**完全不受影響**，付款流程與沒有本功能時一模一樣。
  → 也就是說：除非管理員明確建立「採購訂單」的簽核規則，否則零影響。
* **一張帳單可能對應多張採購單**（``action_create_invoice`` 會依
  公司/供應商/幣別合併），此時**所有**關聯採購單都要核准才放行。
* **只擋廠商帳單**，貸項通知單（``in_refund``，退款作業）不受管制。
* 帳單表單上會出現紅色警示框說明是哪張採購單、目前是什麼審批狀態。

安全閥
~~~~~~

1. **全域開關**：系統參數 ``mfg_custom_purchase_approval.block_payment_without_approval``
   （預設 True = 啟用）。設為 ``False`` 即完全停用，管理員可隨時解除。
2. **管理員放行**：``mfg_custom_base.group_manager`` 的使用者可直接付款，
   系統會在帳單 chatter 留下「管理員放行」的紀錄。放行資格由**伺服器端群組**判定，
   不採信 client 傳來的參數。
3. **錯誤訊息自帶出路**：訊息會寫明是哪張採購單、目前審批狀態、以及該去哪裡送審。

依賴
----

* ``mfg_custom_approval`` — 通用多層簽核引擎
* ``purchase`` — 採購單（會帶入 ``account``）
* ``mail`` — chatter 通知

操作指引
--------

A. 設定審批規則（只需做一次）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

路徑：**設定 → MFG Custom → 設定 → 簽核規則 → 建立**

=========================  ==========================================  ==============================================
欄位                      怎麼填                                     說明
=========================  ==========================================  ==============================================
規則名稱                  例：採購單簽核                              給自己看的
適用單據類型              選 **採購訂單**                             選了這一項，RFQ 才會出現送審按鈕
適用條件 (domain)         先留空                                     留空 = 所有 PO 都要簽；只要大額才簽就填
                                                                 ``[("amount_total", ">=", 500000)]``
簽核期限（天）            例：3                                       超過期限會發逾期提醒
簽核關卡                  按「新增」                                  每一列 = 一個關卡，依序一個一個簽
=========================  ==========================================  ==============================================

**關卡怎麼設**

=========================  ==========================================
欄位                      怎麼填
=========================  ==========================================
關卡名稱                  例：採購主管核准
核准人模式                選「指定群組」
指定群組                  選「採購簽核者」或「採購：Administrator」
最小/最大金額             先留空（= 不限金額）
=========================  ==========================================

B. 送審與簽核（日常作業）
~~~~~~~~~~~~~~~~~~~~~~~~~~

============================  ==================================================
你要做的事                    操作
============================  ==================================================
送出簽核                      PO 表單右上 → **「送出簽核」**
看審批進度                    PO 表單上方的 **簽核狀態**
                              （無需簽核 / 審核中 / 已核准 / 已駁回）
看審批意見                    PO 的 **「審批紀錄」** 分頁
                              （關卡、核准人、決策、決策時間、意見）
看完整簽核單                  PO「審批紀錄」分頁左上角的狀態按鈕 → 開啟簽核單
核准                          簽核單上按「核准目前關卡」；或
                              **MFG Custom → 待我簽核** 找自己的待辦
駁回                          簽核單上按「駁回」並填原因
被駁回後重送                  PO 上再按一次「送出簽核」，流程會重啟
============================  ==================================================

C. 付款
~~~~~~~~~

路徑：**會計 → 廠商帳單 → 選單據 → 登記付款**（或表單上的「Pay」按鈕）

* 若關聯的採購單**尚未核准** → 會跳出訊息告訴你哪張採購單沒批完
* 若沒有任何審批規則（或該採購單沒進審批流程）→ **跟現在完全一樣，不會被擋**

D. 查詢待審批的單據
~~~~~~~~~~~~~~~~~~~~

* **MFG Custom → 待我簽核**：我的待辦
* **MFG Custom → 簽核申請**：所有簽核單彙總（依「業務單據」欄位可看出是哪張單）
* **採購 → 訂單 → 篩選「待簽核」**：只看採購單的審批狀態
