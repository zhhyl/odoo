MFG Custom - Production Issue
=============================

產線問題点管理系統（取代 Enterprise ``helpdesk``）。

* Kanban 看板（依 stage 自動分組）
* 8D 流程欄位（D1 / D2 / D3 / D5 / D7）與 5Why 根因分析
* 改善行動追蹤（deadline、負責人、驗證）
* 從 mrp.production 一鍵新增問題点；品檢單則以「對應品檢」欄位互相連結
* 可升級為 ECO（plm_custom.eco）
* 多部門協作：MO、工序、工作中心、產品、批號、品檢
* 多層簽核（透過 mfg_custom_approval）
* 開立時以電子郵件通知負責人（僅開立當下寄一封，後續狀態異動不再寄信）

狀態與階段
----------

問題点沒有可自行改寫的狀態欄位，進度一律由「階段」``stage_id`` 決定，
``state`` 只是由階段推導出來的唯讀欄位（開立 / 執行改善 / 已結案）。

內建階段流程：

* 開立 → 分析中 → 圍堵中 → 永久對策執行中 → 驗證中 → 已結案
* 階段可於 **MFG Custom > 設定 > 問題点階段** 自行維護；勾選「結案階段」的階段
  即為結案階段（可設多個，系統取第一個）
* 表單上的「結案」「重啟」按鈕會把問題点在結案階段與開立階段之間切換

結案審核（簽核引擎）
--------------------

問題点的結案可走通用簽核引擎（``mfg_custom.approval.mixin``）：

* 「送出簽核」：已結案的問題点不可再送簽
* 所有關卡核准 → 自動移到「已結案」階段，並填入結案日
* 簽核被駁回 → 退回「分析中」階段
* 簽核被取消 → 退回「開立」階段
* 示範規則為「管理部核准」一關，管理者可在 **MFG Custom > 設定 > 簽核規則**
  自行調整

依賴
----

* ``mfg_custom_base`` — 共用 mixin、群組、序號
* ``mfg_custom_approval`` — 結案審核用的通用簽核引擎
* ``mfg_custom_production_stage`` — 產製階段與得料率
* ``mfg_custom_quality`` — 品檢單（互為關聯）
* ``mrp`` / ``project`` — MO 與專案任務的關聯
